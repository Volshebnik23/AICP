# AICP patent and IPR posture

> Maintainer review required: this file is a conservative project policy statement intended to reduce implementation ambiguity. It is not a standards-body patent policy and is not legal advice.

## Baseline posture

AICP is intended to be implementable on a royalty-free basis.

For contributions to repository materials licensed under Apache License 2.0, the Apache-2.0 patent license in [`LICENSE`](LICENSE) is the governing patent grant.

For the AICP normative and informative specifications published from this repository, the project maintainers intend that contributors not assert patent claims that are necessarily infringed by implementing the contributed specification material as written, when that implementation is conforming to the repository's published normative artifacts.

## Scope of the intended commitment

This intended commitment is:

- **non-exclusive**;
- **worldwide**;
- **royalty-free**;
- limited to patent claims that a contributor can license and that are **necessarily infringed** by the contributor's own material incorporated into this repository.

It does **not** extend to:

- claims that would be infringed only by optional implementation choices;
- claims covering features not described in the contributed repository materials;
- third-party patent claims; or
- trademarks, logos, or certification rights.

## Defensive suspension

If a party files patent litigation alleging that this repository, a contribution to it, or a conforming implementation of the contributed AICP materials infringes that party's patents, the project maintainers intend that any project-policy patent commitment from that party be suspended for the duration of that dispute, to the extent permitted by applicable law.

This paragraph is meant to be read conservatively and in harmony with the Apache-2.0 patent-termination model, not as a broader or more aggressive mechanism.

## IPR disclosure expectation

Contributors should disclose, in the pull request or issue tracker, any patent claims they know of that may be necessarily infringed by a proposed normative change and that they own or control, or that they have specific reason to believe may materially affect implementers.

If a contributor is unable to make the intended royalty-free posture for a contribution, that contribution should not be merged until maintainers explicitly review the issue.

## No separate certification regime

AICP does not claim to operate a formal standards-body RAND/RF program, patent pool, or certification authority through this document.
