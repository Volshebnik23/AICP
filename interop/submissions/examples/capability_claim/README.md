# Fictional capability claim

This instructional package demonstrates the M62 `implements_capability`
manifest and generalized external evidence report v2 for
`aicp.session_state_projection@v1`.

The report is generated with the repository's external-kind test adapter.
Neither that adapter nor this example is an independent external
implementation, so the public matrix must never promote its reported mark.

Regenerate the JSON files with:

```bash
python scripts/generate_evidence_submission_example.py --write
```
