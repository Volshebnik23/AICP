# AICP interop submissions

Public interoperability submission manifests use:
- `interop/submissions/submission.schema.json`
- `interop/submissions/examples/` for example-only packages
- `interop/submissions/templates/` for starter templates

Example/template folders are reserved and MUST NOT be treated as real ecosystem submissions.

Real future submissions should use the same `submission.json` shape and point to concrete repo-relative evidence artifacts.
