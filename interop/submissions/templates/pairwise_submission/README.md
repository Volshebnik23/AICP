# Pairwise submission template

This non-promotable template shows the five-file M66 package: one Base
full-profile report and one MCP full-binding report for each exact build, plus
one joint report issued under `AICP-PAIRWISE-TCK-1.1.0`.

Replace every identity and digest placeholder. The joint report's four side
references must resolve beside the joint report and must match the same exact
IDs, versions, and build digests declared in `submission.json`. Generate the
real `bundle-integrity.json` only after all five evidence files have been
copied; the checked-in `bundle-integrity.template.json` is not evidence.

This template, repository clean-room peers, and their test outputs do not count
as external adoption or as a demonstrated public pairwise relation.
